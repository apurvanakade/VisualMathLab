Press and drag your mouse to draw on the left canvas. Each point along your stroke is the “true” signal; it’s corrupted with Gaussian noise, and a constant-velocity 2D particle filter reconstructs your drawing live on the right canvas from that noisy stream alone.

// VM is the shared utility library, loaded globally via _includes/head-scripts.html (js/**). This page uses VM.sampling.seededRandom, VM.sampling.gaussianRandom, VM.filters.particleFilterStep.
VM = window.VM
urlParams = new URLSearchParams(window.location.search)

initialSigma = {
  const raw = Number.parseFloat(urlParams.get("sigma"))
  return Number.isFinite(raw) ? Math.min(Math.max(raw, 1), 100) : 15
}

// Defaults to the well-tuned R = 225 (matching the "Well-tuned" example
// below) so a first-time visitor sees the filter working correctly by
// default; the mistuned examples are one click away.
initialR = {
  const raw = Number.parseFloat(urlParams.get("R"))
  return Number.isFinite(raw) ? Math.min(Math.max(raw, 1), 3000) : 225
}

// Defaults to Q = 100 (matching the "Well-tuned" example below) --
// noticeably higher than the 2D Kalman filter's well-tuned Q = 15,
// because a particle filter's velocity kicks are sampled per-particle
// rather than integrated analytically: too small a Q and no particle's
// random walk ever covers a quick direction change, no matter how many
// particles there are.
initialQ = {
  const raw = Number.parseFloat(urlParams.get("Q"))
  return Number.isFinite(raw) ? Math.min(Math.max(raw, 0), 400) : 100
}

initialN = {
  const raw = Number.parseInt(urlParams.get("N"), 10)
  return Number.isFinite(raw) ? Math.min(Math.max(raw, 10), 1000) : 200
}

  return input
}

// user can start a fresh drawing without reloading the page.
viewof resetTrigger = {
  const btn = Inputs.button("Reset", {value: 0, reduce: v => v + 1})
  btn.classList.add("ojs-auto", "ojs-end")
  return btn
}

  return input
}
viewof Q = {
  const input = Inputs.range([0, 400], {step: 0.5, value: initialQ, label: "Process noise Q"})
  return input
}

  const input = Inputs.range([10, 1000], {step: 10, value: initialN, label: "Particle count N"})

// liveNoise/filterParams read the sigma/R/Q/N controls directly (the
// reactive values, not stable `viewof` snapshots), so they recompute --
// and write back into the URL -- on every change, live, with no commit
// button in between. `sim` below reads these fresh on every generated
// sample -- sigma and N only actually take effect the moment a new
// stroke's noise generator/particle cloud is created (see `sim`'s
// `sampleAt`/`startStroke`), same as a real sensor whose calibration and
// particle budget can't be changed after it's already taken a reading.
liveNoise = {
  const params = new URLSearchParams(window.location.search)
  params.set("sigma", String(sigma))
  history.replaceState(null, "", `${window.location.pathname}?${params}`)

  return {sigma}
}
filterParams = {
  const params = new URLSearchParams(window.location.search)
  params.set("R", String(R))
  params.set("Q", String(Q))
  params.set("N", String(N))
  history.replaceState(null, "", `${window.location.pathname}?${params}`)

  return {R, Q, N}
}
// sim owns both canvases -- a left one the user draws on directly, and a
// right one showing what the filter reconstructs from noisy samples of
// that drawing -- in a closure that persists across reactive
// re-invocations, the same DOM-node-reuse idiom other pages use for a
// Plotly div. As in the 2D Kalman filter page, there is no
// requestAnimationFrame render loop: both canvases are plain accumulating
// ink (like a paint app), drawn incrementally as strokes happen rather
// than cleared and redrawn from a point-history buffer every frame, so a
// mousedown/mousemove/mouseup handler is the entire drawing engine. On
// the right canvas, every sample additionally paints a faint dot for a
// subsample of the current particle cloud -- because the canvas is never
// cleared mid-stroke, these dots layer via canvas alpha blending into a
// translucent "tube" around the reconstructed path, visually growing
// denser wherever the filter's belief stayed tightly clustered and
// fainter/wider wherever it didn't -- which is the one visual particle
// filters can show that a single-Gaussian Kalman belief cannot.
//
// A "stroke" is one mousedown-to-mouseup drag. Lifting the mouse and
// pressing again starts a brand new stroke: the particle filter's whole
// cloud is re-initialized at the new stroke's first point (a previous
// stroke's velocity spread has no bearing on where a freshly-placed pen
// starts), and the two canvases stop connecting a line across the gap,
// matching how the left canvas itself visually breaks between strokes.
// The noise generator, however, is seeded once (from a fixed constant --
// there's no user-facing seed control) and keeps running across the
// whole session; only the particle filter restarts per stroke. Reset goes
// further and clears both canvases entirely, also re-seeding both the
// noise generator and the particle filter's own random stream so a fresh
// drawing gets fresh randomness throughout.
//
// World coordinates == canvas CSS-pixel space: the backing store is
// scaled to devicePixelRatio for a crisp draw, then every draw call is
// issued through that same transform, so canvas coordinates line up
// directly with mouse event offsetX/offsetY with no separate
// pixel-mapping step. Resizing the window clears both canvases' pixel
// buffers (a plain HTML canvas always does this on resize) -- acceptable
// here since this is a prototype and resizing mid-drawing is rare; the
// alternative would mean keeping a full point-history buffer solely to
// redraw after a resize.
sim = {
  const SAMPLE_INTERVAL_MS = 150
  const INITIAL_VELOCITY_STD = Math.sqrt(4000)  // uninformative prior: the filter has no idea which way a freshly-started stroke will move
  const NOISE_SEED = 1     // fixed -- there's no user-facing seed control, so every session/Reset draws measurement noise from the same starting point
  const FILTER_SEED = 2    // separate stream from NOISE_SEED, so the filter's own randomness (init spread, process noise, resampling) never competes with the measurement-noise draws for the same numbers
  const PARTICLES_DRAWN_PER_SAMPLE = 40  // visual subsample of the cloud -- keeps the right canvas legible and fast even when N is in the hundreds
  const colors = {trueC: "#2563eb", noisy: "#9ca3af", particle: "#7c3aed", estimate: "#dc2626"}

  // Builds one bordered canvas box (used for both the left "draw" canvas
  // and the right "reconstruction" canvas) with a caption above it and a
  // centered placeholder message shown until the first stroke begins.
  const makeCanvasBox = (captionText, placeholderText, cursor) => {
    const box = document.createElement("div")
    box.style.cssText = "flex:1 1 320px;min-width:280px;"

    const caption = document.createElement("div")
    caption.style.cssText = "font-size:0.85rem;color:var(--bs-secondary-color, #6b7280);margin-bottom:0.35rem;"
    caption.textContent = captionText

    const frame = document.createElement("div")
    frame.style.cssText = `position:relative;height:55vh;min-height:380px;overflow:hidden;border:1px solid var(--bs-border-color, #dee2e6);border-radius:var(--bs-border-radius, 0.375rem);background:#fff;cursor:${cursor};`

    const canvas = document.createElement("canvas")
    canvas.style.cssText = "width:100%;height:100%;display:block;"

    const placeholder = document.createElement("div")
    placeholder.style.cssText = "display:flex;position:absolute;inset:0;align-items:center;justify-content:center;text-align:center;padding:1.5rem;color:var(--bs-secondary-color, #6b7280);font-size:1.05rem;pointer-events:none;"
    placeholder.textContent = placeholderText

    frame.append(canvas, placeholder)
    box.append(caption, frame)
    const ctx = canvas.getContext("2d")

    const resize = () => {
      const rect = frame.getBoundingClientRect()
      const dpr = window.devicePixelRatio || 1
      canvas.width = Math.max(1, Math.round(rect.width * dpr))
      canvas.height = Math.max(1, Math.round(rect.height * dpr))
      ctx.setTransform(dpr, 0, 0, dpr, 0, 0)
    }
    new ResizeObserver(resize).observe(frame)
    resize()

    return {box, canvas, ctx, placeholder}
  }

  const left = makeCanvasBox("Draw here", "Click and drag to draw.", "crosshair")
  const right = makeCanvasBox("Particle filter reconstruction", "Your reconstructed drawing appears here.", "default")

  const legendItems = [
    {key: "trueC", label: "Your drawing"},
    {key: "noisy", label: "Noisy measurement"},
    {key: "particle", label: "Particle cloud"},
    {key: "estimate", label: "Particle filter estimate"}
  ]
  const legend = document.createElement("div")
  legend.style.cssText = "display:flex;flex-wrap:wrap;gap:0.25rem 1rem;justify-content:center;padding:0.5rem 0;font-size:0.85rem;"
  for (const item of legendItems) {
    const el = document.createElement("span")
    el.style.cssText = "display:inline-flex;align-items:center;gap:0.35rem;"
    const dot = document.createElement("span")
    dot.style.cssText = `width:10px;height:10px;border-radius:50%;background:${colors[item.key]};display:inline-block;`
    el.append(dot, document.createTextNode(item.label))
    legend.append(el)
  }

  const row = document.createElement("div")
  row.style.cssText = "display:flex;flex-wrap:wrap;gap:1rem;"
  row.append(left.box, right.box)

  const outer = document.createElement("div")
  outer.append(row, legend)

  // latestParams holds whatever the OJS output cell most recently passed
  // in; every draw call reads the current value, so a slider change
  // takes effect on the very next sample without touching the drawing
  // already on either canvas.
  let latestParams = null

  let isDrawing = false
  let leftLast = null       // last point drawn on the left canvas for this stroke, or null to start a fresh line segment
  let estimateLast = null   // last particle-filter estimate drawn on the right canvas for this stroke
  let lastSampleTime = null
  let noiseGaussian = null  // seeded once, kept for the whole session (not per stroke)
  let filterRng = null      // seeded once, kept for the whole session (not per stroke)
  let particles = null      // re-initialized at the start of every stroke

  const drawDot = (ctx, x, y, r, color, alpha) => {
    ctx.globalAlpha = alpha === undefined ? 1 : alpha
    ctx.fillStyle = color
    ctx.beginPath()
    ctx.arc(x, y, r, 0, Math.PI * 2)
    ctx.fill()
    ctx.globalAlpha = 1
  }

  const drawSegment = (ctx, from, to, color) => {
    ctx.strokeStyle = color
    ctx.lineWidth = 3
    ctx.lineCap = "round"
    ctx.lineJoin = "round"
    ctx.beginPath()
    ctx.moveTo(from.x, from.y)
    ctx.lineTo(to.x, to.y)
    ctx.stroke()
  }

  // Draws the next point of the true stroke on the left canvas, and
  // returns it -- called on every mousemove while drawing, independent
  // of the slower measurement-sampling cadence below, so the drawn
  // stroke itself is exactly as smooth as the browser's own mousemove
  // events allow.
  const drawTruePoint = (x, y) => {
    const point = {x, y}
    if (leftLast) drawSegment(left.ctx, leftLast, point, colors.trueC)
    drawDot(left.ctx, x, y, 2, colors.trueC)
    leftLast = point
  }

  // Draws one noisy measurement of the current true point, advances the
  // particle filter by exactly one predict+update+resample step, draws a
  // subsample of the resulting particle cloud, and draws the new estimate
  // on the right canvas -- gated to roughly SAMPLE_INTERVAL_MS apart
  // regardless of how often mousemove itself fires, simulating a sensor
  // slower than the mouse.
  const sampleAt = (x, y, now) => {
    const {sigma, R, Q} = latestParams
    if (!noiseGaussian) {
      const rng = VM.sampling.seededRandom(NOISE_SEED)
      noiseGaussian = VM.sampling.gaussianRandom(rng)
    }

    const noisyX = x + sigma * noiseGaussian()
    const noisyY = y + sigma * noiseGaussian()

    const step = VM.filters.particleFilterStep(filterRng, particles, [noisyX, noisyY], {R, Q})
    particles = step.particles
    const estimatePoint = {x: step.estimate.x, y: step.estimate.y}

    drawDot(right.ctx, noisyX, noisyY, 2.5, colors.noisy)
    const stride = Math.max(1, Math.floor(particles.length / PARTICLES_DRAWN_PER_SAMPLE))
    for (let i = 0; i < particles.length; i += stride) {
      drawDot(right.ctx, particles[i].x, particles[i].y, 1.5, colors.particle, 0.35)
    }
    if (estimateLast) drawSegment(right.ctx, estimateLast, estimatePoint, colors.estimate)
    drawDot(right.ctx, estimatePoint.x, estimatePoint.y, 2, colors.estimate)
    estimateLast = estimatePoint

    lastSampleTime = now
  }

  const startStroke = (x, y) => {
    isDrawing = true
    leftLast = null
    estimateLast = null
    lastSampleTime = null

    const {sigma, N} = latestParams
    const posStd = sigma > 0 ? sigma : 1
    particles = new Array(N)
    for (let i = 0; i < N; i++) {
      particles[i] = {
        x: x + posStd * filterRng.gaussian(),
        y: y + posStd * filterRng.gaussian(),
        vx: INITIAL_VELOCITY_STD * filterRng.gaussian(),
        vy: INITIAL_VELOCITY_STD * filterRng.gaussian(),
        weight: 1 / N
      }
    }

    left.placeholder.style.display = "none"
    right.placeholder.style.display = "none"
    drawTruePoint(x, y)
    sampleAt(x, y, performance.now())
  }

  const endStroke = () => {
    isDrawing = false
  }

  // Clears both canvases' pixel buffers, ends any in-progress stroke, and
  // drops the noise generator/filter state so the next stroke starts
  // completely fresh (same as a freshly-loaded page).
  const resetCanvases = () => {
    left.ctx.clearRect(0, 0, left.canvas.clientWidth, left.canvas.clientHeight)
    right.ctx.clearRect(0, 0, right.canvas.clientWidth, right.canvas.clientHeight)
    left.placeholder.style.display = "flex"
    right.placeholder.style.display = "flex"
    isDrawing = false
    leftLast = null
    estimateLast = null
    lastSampleTime = null
    noiseGaussian = null
    filterRng = null
    particles = null
  }

  left.canvas.addEventListener("mousedown", (e) => startStroke(e.offsetX, e.offsetY))
  left.canvas.addEventListener("mouseup", endStroke)
  left.canvas.addEventListener("mouseleave", endStroke)
  left.canvas.addEventListener("mousemove", (e) => {
    if (!isDrawing || !latestParams) return
    const x = e.offsetX
    const y = e.offsetY
    drawTruePoint(x, y)
    const now = performance.now()
    if (lastSampleTime === null || now - lastSampleTime >= SAMPLE_INTERVAL_MS) {
      sampleAt(x, y, now)
    }
  })

  return (params) => {
    const shouldReset = latestParams && params.resetTrigger !== latestParams.resetTrigger
    latestParams = params
    if (shouldReset) resetCanvases()
    if (!filterRng) {
      const uniform = VM.sampling.seededRandom(FILTER_SEED)
      filterRng = {uniform, gaussian: VM.sampling.gaussianRandom(uniform)}
    }
    return outer
  }
}
sim({sigma: liveNoise.sigma, R: filterParams.R, Q: filterParams.Q, N: filterParams.N, resetTrigger})

How the filter works

Unlike the Kalman filter’s single Gaussian belief (a mean and covariance), a particle filter represents its belief as a cloud of \(N\) weighted samples – “particles” – each an independent guess \((x, y, v_x, v_y)\) at the true state. Every incoming measurement runs three steps over the whole cloud:

  1. Predict. Each particle’s velocity takes an independent random step, \(v \mathrel{+}= \mathcal{N}(0, Q)\), then its position advances by that velocity – the same constant-velocity motion model the Kalman filter assumes, just simulated per-particle instead of propagated analytically.
  2. Update. Each particle is reweighted by how likely the new measurement \(z\) is if that particle’s position were the truth, \(w \mathrel{*}= \exp\!\big(-\lVert p - z \rVert^2 / 2R\big)\), then all weights are renormalized to sum to 1. Particles far from \(z\) end up with near-zero weight; particles close to it end up dominating the cloud.
  3. Resample. A fresh set of \(N\) equally-weighted particles is drawn from the current cloud, with each particle’s chance of being kept proportional to its weight. This is what stops the cloud from collapsing onto a handful of particles over many steps (“particle deprivation”) while still concentrating it wherever the evidence points.

The filter’s point estimate at each step – the red trace on the right canvas – is the weighted mean position before resampling. \(R\) and \(Q\) play the same roles here as in the Kalman filter: \(R\) is how much measurement noise the filter assumes, and \(Q\) is how much it lets velocity drift between samples. The one parameter with no Kalman-filter analogue is \(N\): too few particles and the cloud can’t cover the space of plausible positions, so the estimate degrades into a jagged, laggy approximation no matter how well \(R\) and \(Q\) are tuned.
